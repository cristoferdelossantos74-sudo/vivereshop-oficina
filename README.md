# 🏢 VivereShop Oficina

Oficina virtual 3D de VivereShop: ves a tus agentes IA trabajando, descansando y celebrando; los configuras, les pagas (dinero ficticio), contratas nuevos y manejas todo desde la oficina del CEO.

- **Web / PC**: Vite + Three.js, instalable como app (PWA)
- **Android**: APK con Capacitor (se compila solo en GitHub)
- **Login y datos en tiempo real**: Firebase Auth + Firestore (plan gratis)
- **Backend gratis**: Google Apps Script (Google Sheets + IA Gemini)

👉 **Instalación paso a paso: [GUIA.md](GUIA.md)**

```
src/            app (oficina 3D, paneles, agentes)
apps-script/    backend gratis (Code.gs)
wordpress/      snippet para el contador de ZapIA
firestore.rules seguridad de la base de datos
.github/        construye el APK y publica la web
```
